**ON the team page -> project tab**
There's a save progress button (only team members see)
There's a submit for judging button (makes everyone able to see on team page)

**Team name, then we fill in the summary**. Summary is expected to be 50-200 words, high level summary, consider answering 3 questions in it:
1- What did you develop?
2-How does it address the challenge?
3-Why is it important?

**Project links: need to be publicly accessible** Not even a registration needed to see it!!
1- DEMONSTRATION: we need to submit a slides (7 max including title and intro pages)
or video (30 secs max)
2- PROJECT: we submit github repo link or website link (also needs to be publicly accessible)

**Project information**
1- PROJECT DETAILS: questions to consider
- What does your project do, and how does it work?
- What benefits does it have?
- What is the intended impact?
-  What tools, hardware, software, coding languages did you use?
- How is your project creative
- What factors such as energy, cost or accessibility did your team consider?

**Use of SuperIntelligence SI**
LLM, chatbot, image generations... is permitted
RULES:
- Generated content may not use, contain or modify any NASA branding or design elements (including NASA logos, flags and mission identifiers)
- Clearly indicate where and how SI was used (and add a visible watermark to images and videos indicating that they are SI generated)
- Acknowledge SI-generated audio, code, and data in descriptive text and metadata
- Judges will consider originality, intent and execution when reviewing SI-assisted work
(select from dropdown menu)

**NASA data**
To be eligible we have to use at least one NASA data or resource (list it with link url and link text)

**Other data**
also list it with link text and url, must include anything external even if its just text, images, or audio even if it was freely available. If we are using any copyrighted material we need to make sure we have the right to use them.

General rule: no audio, photo or video of anyone under 18

**Participation certificate**
Once project is submitted, we can go in account information and then we see the certificate download button. Letter format better for paper size and it is only in PDF.

**Project judging**
scale of 1-5 on each of these sections:
- IMPACT
- CREATIVITY
- VALIDITY
- RELEVANCE
- PRESENTATION

**AWARDS**
BUoScience, BUoData, BUoTechnology, Galactic Impact, Best mission concept, Most Inspirational, Best storytelling, Global connection, Art and tech, local Impact
